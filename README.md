# harmenx.github.io

Personal portfolio site built with React, Vite, TypeScript, and Tailwind CSS.

## Development

```bash
yarn install
yarn dev
```

Runs locally at http://localhost:8080.

## Build

```bash
yarn build
yarn preview
```

## Deploy

Deploys to GitHub Pages via the `gh-pages` branch:

```bash
yarn deploy
```

Site URL: https://harmenx.github.io
